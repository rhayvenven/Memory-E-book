Memory E-Book

A desktop diary app built with Electron. Save a memory with a photo, a story, a mood, and tags — then browse them by list, by filter, or by calendar.

Install
  npm install
  npm start

Features
- Add a memory with a title, story, photos, mood, and tags
- Browse saved memories with search and mood/tag filters
- View a memory in a polaroid-style detail page
- Browse memories by date on a calendar

Tech Stack
Electron, Node.js, HTML/CSS/JavaScript
